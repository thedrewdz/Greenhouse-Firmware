# Work Item Tracking (pointer)

The canonical, solution-wide work-item tracking process lives in the Greenhouse Documentation
repository: **`work-item-tracking.md`**
(https://github.com/thedrewdz/Greenhouse-Documentation/blob/main/work-item-tracking.md).

Summary for this repository:

- All trackable work (bug, feature, update, tech-debt, standards gap) is a GitHub issue — one
  work item = one issue. File it in this repo before/as you start non-trivial work.
- Every new issue is auto-added to the **Greenhouse Delivery** project board; do not rely on
  manual board adds.
- Priority is the manual rank on the board (top = next); the Priority field is severity
  metadata. Set the type label (`bug`, `enhancement`, `tech-debt`, `standards`).

This local file is supplemental; if it conflicts with the canonical doc, the canonical doc wins.
